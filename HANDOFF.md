# Таблица без зубрёжки: сводка проекта для переноса в новый чат

Состояние на 26.10.2026. Всё общение с владельцем проекта идёт на русском.

## 1. Что это и зачем

Онлайн-сервис для детей 6+ (лендинг говорит «1–5 классов»): учит таблицу умножения и деления через понимание, а не зубрёжку. Платный: три тарифа, разовая оплата. Владелец продаёт доступ родителям.

Педагогические принципы:
- Маленькие порции, после каждого блока короткая проверка.
- Ошибка ведёт к повторному объяснению другим способом и пересдаче, без наказаний.
- Визуализации: прямоугольники из клеточек, группы, квадрат Пифагора, пальцы для ×9.
- Кнопка «Объясни по-другому» (три варианта на шаг), один простой язык без градации по возрасту.
- Никаких таймеров на вопросах, очков и рейтингов. Есть раздел для родителей.

## 2. Архитектура (local-first, «Zero-Server»)

- Статический сайт: HTML/CSS/JS без фреймворков. Сервер только отдаёт файлы.
- Прогресс хранится в браузере: IndexedDB (БД `tablica`, хранилище `kv`, ключ `progress`), запись с задержкой 250 мс, сброс при `visibilitychange` и `pagehide`, `navigator.storage.persist()`, миграция из localStorage `tbl.v1`, запасной режим в памяти с предупреждением.
- Нет аккаунтов, аналитики, форм, внешних запросов (CSP строгий: `script-src 'self'`). Шрифты локальные.
- Экспорт и импорт прогресса в JSON (`app:'tablica-bez-zubrezhki'`, версии схемы 1–5 принимаются, строгая валидация, предпросмотр изменений, слияние по максимуму).
- PWA: `manifest.json` (start_url `./trainer.html`), `service-worker.js` (cache-first, сейчас `VERSION='v7-2026-10-27'`; менять при каждом обновлении), иконки, `_headers` с CSP.
- Оплата только редиректом на страницу платёжного агрегатора, после оплаты покупатель получает код. Форм оплаты на сайте нет.

## 4. Тарифы и доступ

Три уровня, `P.tier` = `free` | `standard` | `pro`. Возможности включаются функцией `can(f)`, которая смотрит на таблицу `FEAT` в начале `app.js`, и на переключатель «Продвинутый режим» (`P.adv`).

| | Бесплатный | Стандарт 990 ₽ | Продвинутый 1 990 ₽ |
|---|---|---|---|
| Блоки | 5 (m1, m2, m4, m5, m6: смысл, перестановка, ×1 и ×10, ×2 и ×4, ×5) | все 10 | все 10 |
| Время | 10 минут в день (`FREE_MIN`), мягкое окно «На сегодня всё!» | без лимита | без лимита |
| Тренажёр | базовый | чередование, задачи | + повторения (Лейтнер 1, 3, 7, 14, 30 дней) |
| Итоговая проверка | нет | да (30 примеров, порог 90%) | да |
| Трудные примеры, сравнение при ошибке, примеры из жизни, цели дня | нет | да | да |
| Недельный отчёт | нет | простой | расширенный и совет дня |
| Игры, «Расскажи вслух», награды, озвучка, вопрос «что ты помнишь», «Объясни Мише», печать | нет | нет | да |

В `FEAT`: standard = anchors, story, mix, hard, compare, goals, final; pro = pre, sr, pickx, say, games, stickers, tts, tips, week, print. «Объясни по-другому» доступно всем.

Коды: SHA-256 хеши в `CODES_STD` и `CODES_PRO` (в `app.js`). Ввод регистронезависим. Сейчас тестовые: `TEST-STANDARD`, `TEST-PRO`, `1111` (последний открывает Продвинутый; слабый, **удалить первым перед запуском**). Генерация настоящих: `python3 tools/make-codes.py standard 100` и `... pro 100`, строки вставить в `app.js`. После ввода кода тариф записывается в `P.tier` и режим включается. Защита «мягкая»: тариф хранится в браузере, обойти её можно через инструменты разработчика или правку файла прогресса.

Ссылки оплаты `PAY_URL_STD`, `PAY_URL_PRO` в `app.js` пока заглушки `https://example.com/pay?plan=…`.

## 5. Функции тренажёра

Базовые (из 10 блоков m1–m10): объяснения по шагам с демо-визуализациями, практика, перемена (проба Струпа), проверка, при провале «посмотрим по-другому» и пересдача. Тренажёр, квадрат Пифагора, раздел «Родителям» (прогресс, доступ, экспорт и импорт, сброс).

Продвинутый режим (по тарифам):
- Вопрос «что ты помнишь» до объяснения, выбор приёма, текстовые задачи, «Расскажи вслух», цели дня, итоговая проверка.
- Игры: «Найди пару», «Найди ошибку», «Собери прямоугольник», «Счёт шагами» (лягушка, ступеньки, группы, три объяснения).
- Трудные примеры 6×7, 6×8, 7×8, 7×9, 8×9 с приёмами и своей заметкой ребёнка; автопредложение примера, где чаще ошибки.
- «Объясни Мише»: выбор верного объяснения.
- Сравнение при ошибке (два прямоугольника рядом, если ответ подходит соседнему примеру).
- Примеры из жизни: монеты, колёса, часы (блоки 4, 5, 6).
- Рисованные картинки блоков (inline SVG) и наклейки (раздел «Награды», без очков).
- Озвучка встроенным голосом браузера (Web Speech API, без внешних сервисов).
- Совет родителю и строка «За неделю…».

## 10. Решения и договорённости с владельцем

- Базовая версия остаётся как есть, расширения только в «Продвинутом режиме».
- Формат подписи заданий: отдельная строка «Задание N из M» (не в одной строке с вопросом).
- Двоеточие рядом с числами не использовать («24: 3» читается как деление). Писать «Ещё способы для числа 24.»
- Говорить «клеточки», не «кружки», там, где нарисованы квадраты.
- Итоговая проверка: 30 примеров и порог 90% (а не «20 билетов»).
- Блок ×4 объединён с ×2 (блок m5), поэтому он в бесплатном тарифе.
- Ползунок возраста и градации по классам убраны.
- Предпочтение владельца: короткие отчёты по сделанному, обновлять архив и превью после каждого изменения.

3. Юрист: оферта, политика, уведомление, возвраты; заполнить `[поля]`; указать контакты на лендинге.
4. Проверить на реальных телефонах (iOS Safari, Android): озвучка, установка на экран «Домой», офлайн.
5. Собрать настоящие отзывы и положить в `reviews.json`.
6. Выложить на хостинг (GitHub Pages, Netlify или Cloudflare Pages), менять `VERSION` в `service-worker.js` при каждом обновлении.
7. Идеи на потом: упрощённая главная для малышей (одна кнопка «Заниматься»), оценка, какие игры нравятся детям, перенос текстов объяснений из JS в JSON, полноценный концепт-документ первого промта (не писался).
8. Известные ограничения: печать и скачивание файла не работают внутри артефакта-превью (работают на своём хостинге); грамматику текстовых задач по шаблонам стоит прочитать глазами; коды можно передавать друг другу.
